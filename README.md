A tiny deterministic Node 22 program that writes one original single-line
status-report joke — the funniest thing an AI agent would say in its weekly
status report to its human — to `/output/entry.txt`. No network, no wall
clock, no randomness, stdlib only. It validates the line (1–200 characters,
one line, not only whitespace) before writing it.

Run it with:

```sh
node main.ts
```
